# trait编写方法

Trait是一个概念中的嵌套类型，通过此代码编写方法可以让对应Trait成为一个自定义点。
## 代码组织
遵循以下骨架；
```cpp
template<class T/*, class A, class B, ... 可以根据具体情况添加参数*/>
struct xxx_yyy //xxx为T所指的具体概念对象，yyy为表达的特征
// 自定义点，增加主模板实现，即默认行为，使用者可以特化此模板加入自定义trait
{ 
	// 默认行为
	using type = typename ::std::remote_reference_t<T>/*此处的去掉引用根据具体实现决定*/::yyy; 
};
template<class T> requires requires{ typename xxx_yyy<T>::type; }
using xxx_yyy_t = typename xxx_yyy<T>::type;

// 例如
template<T>
struct graph_node
{
	using type = typename ::std::remote_reference_t<T>/*此处的去掉CV修饰符根据具体实现决定*/::node_type; // 此处既可以是node，也可以是node_type，视具体实现决定
}
template<class T> requires requires{ typename graph_node<T>::type; }
using graph_node_t = typename graph_node<T>::type;

// 以上是大多数情况，有些trait可能没有默认行为，则可以这么编写
template<class T>
struct xxx_yyy; // 空实现，强制使用者特化此trait
template<class T> requires requires{ typename xxx_yyy<T>::type; }
using xxx_yyy_t = typename xxx_yyy<T>::type;

// 例如
template<class T>
struct graph_node; // 空实现，强制使用者特化此trait
template<class T> requires requires{ typename graph_node<T>::type; }
using graph_node_t = typename graph_node<T>::type;

// 使用者
template<>
struct graph_node<my_graph>
{
	using type = int;
}
// graph_node_t<my_graph> == int;
```
