## 思路

- **职责**：加载器 / 热重载 / 精灵表 / Lua（M3 起）。
- **三方（直接用）**：stb（图像）、sol2 + lua（M3 起）。
- **加载策略**：**运行时直接加载 + 热重载**（直吃 BvN 精灵表 + 元数据）。
- **数据语言**：Lua 表（可脚本化数据，"能声明式就声明式"，便于将来编辑器 / 校验）。语言现在定、深度（配置-only vs 纯 Lua 内容）推迟到 M3；M0–M2 零 Lua。
- **资源所有权原则**：子对象依赖父对象资源时，优先把该资源**所有权移交给子对象**独立持有；不加"对比父版本号→重建"逻辑（见 decisions.md 横切原则）。

> 数据 / Lua 热重载与 C++ 热重载的分工见 plugin/hot-reload.md。
