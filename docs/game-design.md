## 1. 一句话定义

一个**从零用原生 C++ 自研引擎**打造的、**2.5D 二次元风格的在线 5v5 英雄 MOBA**：斜俯视视角、固定英雄阵容、技能驱动战斗、三线带野区、完整经济系统（小兵 / 打野 / 金币 / 局内升级 / 出装），单局 8~15 分钟，推塔摧毁敌方基地获胜。

定位：**长期个人作品集项目**。真正的看点不止游戏本身，而是背后那套**自研引擎 + 渲染抽象 + 网络同步**。

---

## 🎯 核心设计哲学（贯穿全局）：用 MOBA 成长表达番剧强度，而非格斗分阶

角色定位（坦 / 输出 / 辅）只是大方向，**角色设计极其灵活**。灵感是"死神 vs 火影"式的番剧群像格斗，但用 **MOBA 的等级 + 装备 + 节奏**给它深度（而非传统 2D 格斗那种单一）：

- **差异化的基础属性模板**：不同角色可以有本质不同的属性机制——比如剑八天生高护甲、抗揍又能爆发，而非"数值高一点的坦克"。
- **差异化的强度曲线**：成长型角色（一护、鸣人）靠等级 / 装备体现"前期弱、后期强"的成长弧；番剧里本就很强的角色可设计成"前期强、后期乏力"。
- **以曲线平衡，而非分阶**：不靠传统格斗"为公平给角色分等级 / 限定形态"（否则蓝染打初始一护必然暴打），而是用成长节奏让强弱随时间自然流动——**每个角色都有自己的强势窗口**，公平来自"你有你的时代、我有我的时代"。
- **技术含义**：需要一套**高度数据驱动、允许逐角色改写规则（属性 / 减伤 / 资源 / 被动）的角色系统**——"角色 = 数据 + 可插拔效果 / 规则"，而非写死的类。

| 维度 | 结论 |

| 局内系统 | **完整经济**：小兵推线、野怪、击杀 / 补刀给金币经验、局内升级、买装备 |

| 单局时长 | 8~15 分钟 |
| 跨局养成 | **无**（每局从头开始，公平竞技，同 LoL） |
| 平台 | PC，**Windows 优先**，保留跨平台可能 |
| 人数 | 在线 5v5（10 人） |

## 4. 关键设计影响与注意点

1. **2 朝向精灵 + 技能型 MOBA 的"瞄准可读性"问题**：角色只有左右两面，玩家不易从立绘看出技能朝向。**对策**：所有技能 / 普攻都配**地面瞄准指示器（telegraph）**，施法时在地面画出弹道 / 范围。M3 即纳入。

2. **"完整经济 + 三线 + 5v5 + 自研引擎 + 单人 + 弹性时间"是独立开发的极限组合**。可行的唯一方式是**里程碑切得极小、每步都能独立运行 / 展示**。**建议第一可玩版本先用 1 条路验证**，跑通后再扩成 3 路。

3. **手感与控制（A 层已锁定）**——这是个 **键盘优先的"动作 MOBA"**：
   - **控制**：WASD 移动 + JKLUIOP 技能 + 鼠标仅辅助，**必须能纯键盘玩**。
   - **瞄准模型（混合）**：指向类技能朝"朝向 / 移动方向"发射 + 地面指示器；指定类 / 普攻用**软锁定**（最近 / 可切换目标）；自身 / 范围技能以自己为中心；鼠标可选精修。
   - **普攻（弱化）**：保留普攻但不强调；补刀更宽松（如范围内击杀即计入金币），降低精度门槛、贴合键盘动作流。
   - **战斗节奏**：中长 TTK，偏策略，宽容网络延迟；数值做成可调参数。
   - **镜头**：固定斜俯角 + 跟随 + 可小幅拉动。
   - **视野**：先全图可见，**架构预留**按队伍裁剪可见性（战争迷雾 / 草丛后期再加）。
   - **输入层**：抽象成"移动向量 / 瞄准 / 技能触发"，不写死按键（手柄暂不做，但低成本预留）。
   - **连带影响**：键盘输入流天然适合未来 lockstep；与"2 朝向精灵"契合。

4. **英雄与技能框架（B 层已锁定）**：
   - **职能**：三大定位 坦克 / 输出 / 辅助（输出再分近战 / 远程）。
   - **技能槽**：少而深的**连招 / 派生**式 —— J/K/L 核心招式（带派生）、U 大招、I/O/P 通用键（闪避 / 装备主动 / 回城）。
   - **连招机制工具箱**：连段序列 + 蓄力长按 + 命中·状态·格挡派生（**不做**方向派生，WASD 仅用于走位 / 瞄准）。
   - **资源**：CD + 蓝条，蓝作为"连招预算"（偏宽松，限制无限连而非"没蓝就废"）。
   - **MVP 英雄数**：3 个（一坦一输出一辅助），长线目标 12+。
   - **味道参照**：格斗 / 动作连招博弈 × MOBA 推塔经济。

## 6. 主要风险

| 风险 | 对策 |
|---|---|
| MOBA 联网（确定性 + 海量单位）最难 | 仿真从 M0 起解耦 + 定步长 + 确定性友好；netcode 先简单后升级 |
| 自研引擎 + 完整 MOBA + 单人，体量巨大 | 里程碑细切、占位美术、先 1 路再 3 路、M5 前不碰联网/CUDA |
| Vulkan+CUDA 双后端拖慢前期 | CUDA 是后期实现；前期只建抽象（抽象便宜，实现延后） |
| 2 朝向精灵看不清技能朝向 | M3 起强制地面瞄准指示器 |
| 完整经济内容量大 | 英雄 / 装备先少（MVP 3~5 英雄），跑通再扩 |

## 附录 B · 深化决策记录

### A 层 · 手感与控制（2026-06-14）
- 控制：WASD + JKLUIOP + 鼠标辅助，纯键盘可玩
- 瞄准模型：混合（方向指示器 + 软锁定 + 自身中心）
- 普攻：弱化（补刀宽松，范围内击杀计入金币）
- 战斗节奏：中长偏策略
- 视野：先全图可见，架构预留迷雾
- 手柄：暂不做，输入层预留抽象

### B 层 · 英雄与技能框架（2026-06-14）
- 职能体系：三大定位（坦克 / 输出 / 辅助，输出分近战 / 远程）
- 技能槽：更动作化的连招 —— JKL 派生 + U 大招 + I/O/P 通用
- 连招机制：连段序列 + 蓄力长按 + 命中·状态·格挡派生（不做方向派生）
- 资源：CD + 蓝条（蓝 = 连招预算，偏宽松）
- MVP 英雄数：3 个（坦 / 输出 / 辅助）

### C 层 · 地图与目标（2026-06-14）
- 地图规模：紧凑快节奏（王者式，主打 8~15 分钟）
- 结构：对称镜像三线 + 河道 + 野区，左下 / 右上基地 + 泉水
- 防御塔：每路 3 塔 + 基地塔（塔耐久调低以配合快节奏）
- 野区：精简（出钱野怪、无复杂 Buff）
- 史诗目标：暂不做（后期再加）
- 胜负：摧毁敌方基地核心；视野先全图可见，草丛几何预埋

### D 层 · 经济与成长（2026-06-14）
- 金币来源：宽松补刀（范围击杀计钱）+ 击杀 / 助攻 + 拆塔 + 出钱野怪 + 少量被动金
- 经验 / 等级：靠近死亡单位吃经验，封顶约 15 级
- 技能升级：自选加点（J/K/L/U）
- 装备：完整自由出装 + 合成（目标），首期先一小套核心装，分批扩
- 主动装备：要，O 键触发，分批引入

### E 层 · 数值与平衡（2026-06-14）
- 伤害类型：物理 + 魔法 + 真伤
- 强度曲线：温和（有前 / 中 / 后期偏向，但任何阶段都不沦为拖累）
- 平衡方法：以整条曲线平衡，接受时刻性不对称
- 时长控制：高地兵营增强 + 后期全局递增 + 翻盘补偿 + 投降（四件套全上）

### F 层 · 元游戏（2026-06-14）
- 进入：房间制 + bot 补位（MVP），后期自动匹配
- 选人：初期盲选 → 后期征召 ban/pick；每队不重复英雄
- 结算：完整（KDA / 伤害 / 经济曲线 / MVP），分步实现
- 账号：无，仅显示名 + 会话身份

### G 层 · 表现（2026-06-14）
- 占位美术：使用用户的《死神 vs 火影》素材（2D 格斗精灵，正好契合 2 朝向，且即番剧角色本身）；版权仅限自用 / 原型，公开发布需替换
- 打击感：先留钩子（受击 / 顿帧 / 屏震 / 特效接口），后期打磨
- 音频：先免费音效，BGM 后期；藏在 IAudio 后
- HUD：标准 MOBA HUD + 连招 / CD 反馈；M3 起做瞄准指示器
- 2D 动画：精灵表 + 战斗状态驱动的动画状态机
