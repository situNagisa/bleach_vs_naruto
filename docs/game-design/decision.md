## 3. 深化决策记录（2026-06-14）

### A 层 · 手感与控制
- 控制：WASD + JKLUIOP + 鼠标辅助，纯键盘可玩
- 瞄准模型：混合（方向指示器 + 软锁定 + 自身中心）
- 普攻：弱化（补刀宽松，范围内击杀计入金币）
- 战斗节奏：中长偏策略
- 视野：先全图可见，架构预留迷雾
- 手柄：暂不做，输入层预留抽象

### B 层 · 英雄与技能框架
- 职能体系：三大定位（坦克 / 输出 / 辅助，输出分近战 / 远程）
- 技能槽：更动作化的连招 —— JKL 派生 + U 大招 + I/O/P 通用
- 连招机制：连段序列 + 蓄力长按 + 命中·状态·格挡派生（不做方向派生）
- 资源：CD + 蓝条（蓝 = 连招预算，偏宽松）
- MVP 英雄数：3 个（坦 / 输出 / 辅助）

### C 层 · 地图与目标
- 地图规模：紧凑快节奏（王者式，主打 8~15 分钟）
- 结构：对称镜像三线 + 河道 + 野区，左下 / 右上基地 + 泉水
- 防御塔：每路 3 塔 + 基地塔（塔耐久调低以配合快节奏）
- 野区：精简（出钱野怪、无复杂 Buff）
- 史诗目标：暂不做（后期再加）
- 胜负：摧毁敌方基地核心；视野先全图可见，草丛几何预埋

### D 层 · 经济与成长
- 金币来源：宽松补刀（范围击杀计钱）+ 击杀 / 助攻 + 拆塔 + 出钱野怪 + 少量被动金
- 经验 / 等级：靠近死亡单位吃经验，封顶约 15 级
- 技能升级：自选加点（J/K/L/U）
- 装备：完整自由出装 + 合成（目标），首期先一小套核心装，分批扩
- 主动装备：要，O 键触发，分批引入

### E 层 · 数值与平衡
- 伤害类型：物理 + 魔法 + 真伤
- 强度曲线：温和（有前 / 中 / 后期偏向，但任何阶段都不沦为拖累）
- 平衡方法：以整条曲线平衡，接受时刻性不对称
- 时长控制：高地兵营增强 + 后期全局递增 + 翻盘补偿 + 投降（四件套全上）

### F 层 · 元游戏
- 进入：房间制 + bot 补位（MVP），后期自动匹配
- 选人：初期盲选 → 后期征召 ban/pick；每队不重复英雄
- 结算：完整（KDA / 伤害 / 经济曲线 / MVP），分步实现
- 账号：无，仅显示名 + 会话身份

### G 层 · 表现
- 占位美术：使用《死神 vs 火影》素材（2D 格斗精灵，正好契合 2 朝向，且即番剧角色本身）；版权仅限自用 / 原型，公开发布需替换
- 打击感：先留钩子（受击 / 顿帧 / 屏震 / 特效接口），后期打磨
- 音频：先免费音效，BGM 后期
- HUD：标准 MOBA HUD + 连招 / CD 反馈；瞄准指示器
- 2D 动画：精灵表 + 战斗状态驱动的动画状态机
