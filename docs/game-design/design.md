## 1. 一句话定义

一个 **2.5D 二次元风格的在线 5v5 英雄 MOBA**：斜俯视视角、固定英雄阵容、技能驱动战斗、三线带野区、完整经济系统（小兵 / 打野 / 金币 / 局内升级 / 出装），单局 8~15 分钟，推塔摧毁敌方基地获胜。

---

## 2. 核心设计哲学：用 MOBA 成长表达番剧强度，而非格斗分阶

角色定位（坦 / 输出 / 辅）只是大方向，**角色设计极其灵活**。灵感是"死神 vs 火影"式的番剧群像格斗，但用 **MOBA 的等级 + 装备 + 节奏**给它深度（而非传统 2D 格斗那种单一）：

- **差异化的基础属性模板**：不同角色可以有本质不同的属性机制——比如剑八天生高护甲、抗揍又能爆发，而非"数值高一点的坦克"。
- **差异化的强度曲线**：成长型角色（一护、鸣人）靠等级 / 装备体现"前期弱、后期强"的成长弧；番剧里本就很强的角色可设计成"前期强、后期乏力"。
- **以曲线平衡，而非分阶**：不靠传统格斗"为公平给角色分等级 / 限定形态"（否则蓝染打初始一护必然暴打），而是用成长节奏让强弱随时间自然流动——**每个角色都有自己的强势窗口**，公平来自"你有你的时代、我有我的时代"。

> 对角色系统的要求（数据驱动、逐角色可改写规则）属实现，见 [engine-spec §1 核心哲学（英雄=协程）](../engine-spec.md#1-核心哲学一切的定调) / [plugin/spec.md](../plugin/spec.md#bvn-插件系统pluginspec)。

## 3. 游戏设计总览

| 维度 | 结论 |
|---|---|
| 品类 | 5v5 英雄 MOBA（节奏比传统 MOBA 略快） |
| 视角 | 侧上方俯视 |
| 维度 | 2.5D —— 3D 场景 + 2D 角色 |
| 角色呈现 | 2D billboard 精灵，**仅左右 2 个朝向**（翻转代替多朝向，省动画） |
| 美术风格 | 卡通 / 二次元（前期占位，后期补真美术） |
| 英雄系统 | **固定英雄阵容**，每个英雄技能组固定、个性鲜明 |
| 战斗核心 | **技能驱动**（WASD 移动 + JKLUIOP 技能，弱化普攻），强调配合与操作 |
| 地图 | **三线 + 野区**（标准 MOBA 生态） |
| 局内系统 | **完整经济**：小兵推线、野怪、击杀 / 补刀给金币经验、局内升级、买装备 |
| 胜负目标 | 推塔分路，摧毁敌方基地 |
| 单局时长 | 8~15 分钟 |
| 跨局养成 | **无**（每局从头开始，公平竞技，同 LoL） |
| 平台 | PC，**Windows 优先**，保留跨平台可能 |
| 人数 | 在线 5v5（10 人） |

## 4. 核心循环

选英雄 → 进场 → 清兵 / 打野攒经济 → 升级技能、出装变强 → 团战 / 抓人争夺优势 → 推塔 → 摧毁基地。

---

## 5. 手感与控制

这是个**键盘优先的"动作 MOBA"**：

- **控制**：WASD 移动 + JKLUIOP 技能 + 鼠标仅辅助，**必须能纯键盘玩**。
- **瞄准模型（混合）**：指向类技能朝"朝向 / 移动方向"发射 + 地面指示器；指定类 / 普攻用**软锁定**（最近 / 可切换目标）；自身 / 范围技能以自己为中心；鼠标可选精修。
- **普攻（弱化）**：保留普攻但不强调；补刀更宽松（范围内击杀即计入金币），降低精度门槛、贴合键盘动作流。
- **战斗节奏**：中长 TTK，偏策略，宽容网络延迟；数值做成可调参数。
- **镜头**：固定斜俯角 + 跟随 + 可小幅拉动。
- **视野**：先全图可见，后期加战争迷雾 / 草丛。
- **输入**：抽象成"移动向量 / 瞄准 / 技能触发"，不写死按键（手柄暂不做）。

## 6. 英雄与技能框架

- **职能**：三大定位 坦克 / 输出 / 辅助（输出再分近战 / 远程）。
- **技能槽**：少而深的**连招 / 派生**式 —— J/K/L 核心招式（带派生）、U 大招、I/O/P 通用键（闪避 / 装备主动 / 回城）。
- **连招机制工具箱**：连段序列 + 蓄力长按 + 命中·状态·格挡派生（**不做**方向派生，WASD 仅用于走位 / 瞄准）。
- **资源**：CD + 蓝条，蓝作为"连招预算"（偏宽松，限制无限连而非"没蓝就废"）。
- **MVP 英雄数**：3 个（一坦一输出一辅助），长线目标 12+。
- **味道参照**：格斗 / 动作连招博弈 × MOBA 推塔经济。

---

## 7. 关键可读性设计：2 朝向精灵的瞄准问题

角色只有左右两面，玩家不易从立绘看出技能朝向。**对策**：所有技能 / 普攻都配**地面瞄准指示器（telegraph）**，施法时在地面画出弹道 / 范围。
