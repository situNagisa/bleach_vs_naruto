vulkan那些有生命周期的对象，封装成一个xxx_observer（持有句柄和操作），以及一个继承了xxx_observer的xxx（管理生命周期），每个对象一个文件，都在vkkl命名空间下
遵循docs里的c++编码规范
1. 去掉所有的访问限制符，所有的成员都是public的。
2. 去掉所有的getter函数，结构体直接对外暴露数据成员。
3. observer不拥有任何构造，赋值函数，observer只明确定义vulkan提供的对应函数，此外不允许有任何其他函数。
4. xxx只允许拥有构造，赋值函数，此外不允许有任何其它函数，不允许有转换函数，不允许有辅助函数，所有的移动赋值实现为：
    a）将*this移动到auto temp；
    b）exchange(other)；移动构造实现为exchange；
5. 不允许有任何辅助函数！！！ 
6. 任何构造函数如果可以是平凡的，那么就让它是平凡的
