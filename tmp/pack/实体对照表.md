# sdag 概念模型 ⇄ 现有 C++ 实体对照

说明：
- 迁移时按「模块」找实体。每个实体给出完整限定名（`sdag::` 之后），种类，现在所在的文件:行，以及实现模式。
- 实现模式：`共用` = 只有一份；`反射` / `模板` = 同一个实体在 `SDAG_REFLECTION` 两种模式下各有一份，迁移时按「接口相同」处理，模板版最终会删除。
- 同一个名字有多个声明（重载、偏特化）时，合并成一行，并标出个数。
- 标注 **拆分 / 删除 / 重名** 的是现有实体与模型不一一对应的地方。
